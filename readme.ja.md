# Digital Clock for Streaming Overlays

![](https://img.shields.io/badge/version-v2026.10-blue)
![](https://img.shields.io/badge/LICENSE-MIT-green)

[English](readme.md)

OBS のブラウザソースなど、配信画面に重ねて使うためのデジタル時計（`clock.html` 1ファイル）です。15種類のデザインを切り替えられ、背景は透過です。設定を調整して、結果の URL をコピーするパネルも付いています。

[Sample](https://mafumafuultu.github.io/clock/clock.html?design=pop&scale=1.5&font=Kosugi+Maru&dev=on)

![](./image.jxl)

## 使い方

1. `clock.html` を任意の場所に置きます。
2. OBS で **ブラウザ** ソースを追加し、**ローカルファイル** にチェックを入れて `clock.html` を指定します。
   パラメータは、ローカルファイルのパスの後ろに付けられます（例: `clock.html?design=pop`）。自分でサーバーに置く場合は、通常の URL で指定します。
3. ページの背景は透過なので、ゲーム画面などにそのまま重ねられます。

```
clock.html?design=pop&format=kanji&scale=1.5&font=Kosugi+Maru
```
## 調整パネル（`?dev=on`）

`dev=on` を付けると、右上にパネルが表示されます。

- 入力欄: `design`、`format`、`scale`、`width`、`font`、`fontTime`、`fontDate`、`bg`（チェックボックス＋色）、`tz`（タイムゾーン候補つき）
- 入力すると、すぐ時計に反映されます。
- 結果は、読み取り専用の欄に `location.search` の形で出ます（例: `?design=pop&format=kanji&scale=1.5`）。
  - `CONFIG` の既定値と違う項目だけが並びます。
  - `dev=on` は含まれません。
- **?～ をコピー** はクエリ文字列だけを、**URLごとコピー** はファイルのパスとクエリ文字列をコピーします。クリップボード API が使えない環境では、代替の方法でコピーします。
- 編集のたびにアドレスバーも更新します（`?dev=on&…`）。リロードしても設定が残ります。
- 「−」ボタンでパネルを小さくできます。
- 不正な `tz` や `width` を入力すると、入力欄が赤くなります。


## 表示形式

| 項目 | 形式 |
|---|---|
| 時刻 | 24時間表記の `HH:MM`（例: `14:35`） |
| 日付（`format=slash`） | `YYYY/MM/DD`（例: `2026/10/17`） |
| 日付（`format=kanji`） | `YYYY年MM月DD日`（例: `2026年10月17日`） |
| 曜日（`slash`） | 英語3文字: `Sun` `Mon` `Tue` `Wed` `Thu` `Fri` `Sat` |
| 曜日（`kanji`） | 漢字1文字: `日` `月` `火` `水` `木` `金` `土` |

- `#time` の `datetime` 属性は `HH:MM`、`#calender` の `datetime` 属性は常に `YYYY/MM/DD` です。
- `format=kanji` のとき、`pop` と `wa` は曜日の前後に全角括弧が付き、`（土）` のように表示されます。
- 表示は秒の頭に合わせて1秒ごとに更新します。時刻は `Date` から取得します。

## パラメータ

URL のクエリで指定するか、スクリプト冒頭の `CONFIG` を書き換えます。**URL パラメータが優先されます。**

| パラメータ | 既定値 | 内容 |
|---|---|---|
| `design` | `simple` | デザインのクラス名（下記） |
| `format` | `slash` | `slash` または `kanji` |
| `scale` | `1` | 全体の拡大率。サイズはすべて `em` 指定なので、比率は保たれます |
| `width` | （空） | 時計全体の幅（例: `width=480` は480px。`30em` や `50vw` など単位つきも可）。指定すると自動の幅調整を行わず、その幅をそのまま使います |
| `font` | （空） | 時刻・日付の両方に使うフォント名 |
| `fontTime` | （空） | 時刻だけのフォント名（`font` より優先） |
| `fontDate` | （空） | 日付・曜日だけのフォント名（`font` より優先） |
| `bg` | （空） | 確認用の背景色（例: `bg=%23223344`）。空なら透過 |
| `tz` | （空） | タイムゾーン（例: `tz=Asia/Tokyo`）。空なら端末の設定 |
| `dev` | （なし） | `dev=on` で調整パネルを表示 |

- `font` / `fontTime` / `fontDate` が空のときは、各デザイン既定のフォントを使います。
- フォント名は、Google Fonts にあれば自動で読み込みます。端末にインストール済みのフォントも使えます。空白は `+` でも書けます。
- 不正な `tz` を指定したときは、端末のタイムゾーンで表示します。
- 不正な `width` は無視され、自動調整になります。
- `dev` は `CONFIG` に含まれないので、出力される URL には入りません。

## 枠サイズの固定

プロポーショナルフォントでは数字によって文字の幅が変わるため、枠があると伸び縮みしてしまいます。これを防ぐため、現在のデザイン・フォント・サイズで取りうる最大幅を実測して、枠を固定しています。

- **時刻**: `00:00`〜`99:99`（同じ数字を繰り返したもの）のうち最大の幅
- **日付**: 0〜9の各数字で年月日を組み立てたうち最大の幅
- **曜日**: 7曜日のうち最大の幅
- 幅は `em` 単位の CSS 変数（`--time-w`、`--cal-w`、`--week-w`）に入ります。
- フォントの読み込み完了後と、デザイン・日付形式・フォントを変えたときに、測り直します。
- あわせて `font-variant-numeric: tabular-nums` も指定しているので、等幅数字に対応したフォントでは、数字の幅も揃います。

枠の大きさは変わりませんが、数字の幅が不揃いなフォントでは、枠の中で文字が数px動くことがあります（中央揃えです）。

### 幅を手動で指定する（`width`）

`width` を指定すると、上の実測を行わず、時計全体にその幅をそのまま使います（`box-sizing: border-box` なので、余白や枠線を含んだ幅です）。中身は、その幅の中で中央に置きます。

- 数字だけなら px で、`scale` の影響は受けません。`scale` に合わせて変えたいときは、`em` などの単位を付けてください。
- 文字は折り返しません。幅が足りないと、中身がはみ出します。


## 動作環境と注意点

- ES2015 以降に対応したブラウザで動作します。外部スクリプトは使わず、Google Fonts のスタイルシートだけを読み込みます。
- Google Fonts からフォントを読み込むには、ネットワーク接続が必要です。オフラインでは代替フォントで表示されます。
- `glass` は `backdrop-filter` を使います。OBS のブラウザソースが未対応のときは、半透明の背景だけになります。
- フォントの太さはパラメータで指定できません。太く見せたいときは、太字のフォントを選んでください。
- パネルや枠がないのは `simple` と `outline` だけです。ほかのデザインは独自のパネルや枠を描くので、明るい場面と暗い場面の両方で見え方を確認してください。
- タイムゾーンの変換には `Intl.DateTimeFormat` を使っています。
